## 개요

OpenClaw v2026.6.6이 2026년 6월 12일에 올라왔습니다. 이번에는 화려한 신기능보다 기본기를 다지는 쪽입니다. 트랜스크립트, 샌드박스, 호스트 환경, MCP stdio, Codex HTTP까지 묶어서 보안 경계를 한 번에 조이고, 텔레그램·iMessage·브라우저 같은 실제 운용 환경에서 자주 부딪히던 문제를 정리했습니다. 시동도 빨라졌고요. 정리하면, 매일 쓰는 사용자가 가장 먼저 체감할 만한 업데이트입니다.

---

## 핵심 요약

- **보안 경계 일괄 강화**: 트랜스크립트, 샌드박스 바인드, 호스트 환경 상속, MCP stdio, Codex HTTP 접근까지 한 번에 좁혔습니다.
- **텔레그램·iMessage 안정성**: 계정 범위 토픽 라우팅 개선, 도구 호출 중에도 스트리밍 텍스트 유지, iMessage 인바운드 상시 재시작과 견고한 echo 마커.
- **브라우저·MCP 연결성**: 기존 세션 CDP 연결 지원, WebSocket 검증 강화, 브라우저 출력 경계 안전 처리.
- **시동 지연 단축**: 모델 메타데이터 캐시 도입, 카탈로그 대기 제거, 슬래시 커맨드 지연 로딩으로 컨트롤 UI가 가볍게 뜹니다.
- **버그 수정 폭이 넓음**: WhatsApp, Feishu, Mattermost, LINE, Discord, OpenAI Realtime까지 채널 전반에서 자잘한 전달 문제를 정리.
- **무릇 운영 신호 강화**: 첫 이벤트 트레이싱, 느린 첫 응답 경고로 문제를 더 일찍 잡습니다.

## 본문

### 보안 경계, 한 번에 조였습니다

이번 릴리즈에서 가장 무게가 실린 부분입니다. 릴리즈 노트의 표현 그대로 옮기면 "security boundaries are substantially tighter across transcripts, sandbox binds, host environment inheritance, MCP stdio, Codex HTTP access" 입니다. 한 마디로, 외부와 닿는 지점 다섯 군데를 동시에 좁혔다는 뜻입니다.

승인 타임아웃 처리와 발신자 검증 로직도 손봤습니다. 삭제된 에이전트와 루프백 도구에 대한 접근 제어도 정리됐습니다. 이전에는 지운 줄 알았던 에이전트가 백채널로 살아남는 듯한 상황이 가끔 보였는데, 그 경계가 명확해졌습니다.

### 텔레그램·iMessage — 매일 쓰는 채널을 먼저

텔레그램 쪽에서는 계정 범위 토픽 라우팅이 더 견고해졌습니다. 도구 호출이 중간에 끼어도 스트리밍 텍스트가 끊기지 않게 유지되고, 콜백 처리와 캐시 관리도 정리됐습니다. 채팅 도중 화면이 갑자기 잘리는 경험을 줄이는 수정입니다.

iMessage는 항상 켜진 인바운드 자동 재시작이 들어갔습니다. 끊기면 알아서 살아납니다. 응답 흐름을 잘게 끊어 보내는 블록 스트리밍, 그리고 메시지 중복이나 누락을 잡는 echo 마커가 더 끈질겨졌고, 아웃바운드 트랜스포트도 단단해졌습니다.

### 브라우저·MCP — 이미 떠 있는 세션에 붙기

이번부터는 이미 떠 있는 크롬에 CDP(Chrome DevTools Protocol)로 붙을 수 있습니다. 매번 새 브라우저를 띄우지 않아도 됩니다. WebSocket 핸드셰이크 검증이 강화됐고, 브라우저가 뱉는 출력의 경계 처리도 안전해졌습니다.

자동화 흐름에서 로그인 세션을 유지해야 할 때, 그리고 사용자 본인의 브라우저 환경을 그대로 활용하고 싶을 때 체감이 다릅니다.

### 컨트롤 UI 시동, 눈에 띄게 빨라졌습니다

모델 메타데이터를 캐시해 두는 것만으로도 시동이 빨라집니다. 시작할 때마다 카탈로그를 끝까지 기다리던 단계가 사라졌고, 슬래시 커맨드는 처음 호출되는 시점에 지연 로딩됩니다.

같이 들어온 진단 도구도 쓸 만합니다. 첫 어시스턴트 이벤트가 트레이싱되고, 첫 답변이 늦으면 경고가 뜹니다. 어디서 막혔는지 짚을 단서가 늘었습니다.

### 변경점 요약

- **CLI·관측성**: Claude CLI 진행 이벤트 노출, 도구 코멘터리를 채널 진행 이벤트로 연결, 첫 이벤트 트레이스, 느린 첫 응답 경고.
- **플러그인·ClawHub**: 재사용 패키지 발행 지원, 드라이런 발행은 승인 우회, 매니지드 플러그인 버전 드리프트 리포트, 은퇴한 Skill Workshop 설정 경고.
- **메모리·프로바이더**: 로컬 llama.cpp 런타임이 프로바이더 플러그인으로 이전, 임베딩 파일 배치, 에이전트 모델 카탈로그 캐시 영속화, QMD JSON 검색 최적화.
- **채널·모바일**: QQBot 그룹 멘션 토글, iPad·iPhone 컨트롤 표면 개선, TUI 풋터에 활성 연결 호스트 노출.

### 버그 수정 — 폭이 넓고 잘게 듬

세션 재바인드 후 남아 있던 승인 후속 호출이 정리됩니다. 답장 큐 항목을 정체성 단위로 비워내는 처리, 스테일 메인·가시 답장 복구, Codex 컨텍스트 엔진 컴팩션 소유권 보존도 포함됐습니다. 기본 컴팩션 타임아웃은 180초로 낮아졌고, 프로바이더 장애 시 터미널 라이프사이클 상태 표시가 바로잡혔습니다.

콘텐츠 경계 쪽에서는 Codex/Harmony 프로토콜 아티팩트, 브라우저·LanceDB 미디어 지시문이 더 이상 새어 나오지 않습니다. 트랜스크립트 이미지 리덕션이 들어갔고, 네이티브 `/compact` 답변 보존도 챙겼습니다.

채널 전달 쪽 수정도 촘촘합니다. WhatsApp 재시작 후 답장 첨부 캡처, Feishu 레이트 리밋 재시도, Mattermost 스레드 답장 보존, LINE 웹훅 경로 정규화, Discord 답장 복구 복원, OpenAI Realtime WebRTC 트랜스크립트 표시까지 한꺼번에 손봤습니다.

프로바이더와 Codex에서도 쿼터 오류 메시지 정리, Codex 합성 사용량 라인 복원, ACP 모델 참조 정규화, Gemma 4 `reasoning_content` 보존, 로컬 모델 가디언 리뷰 우회가 들어갔습니다. 빌드·업데이트 쪽은 패키지 게이트웨이 재시작 복구, 플러그인 컨버전스 수리 가시화, PATH 없는 pnpm 환경의 corepack 폴백, 그리고 모든 검증이 통과할 때까지 베타 GitHub 릴리즈 페이지를 드래프트로 유지하는 정책이 추가됐습니다.

UI 쪽도 빼놓을 수 없습니다. 사용자의 명시적 의도가 있어야 채팅 세션이 열리고, 세션 전환 후 채팅 큐가 깨끗하게 비워집니다.

## 실무자가 볼 핵심 포인트

보안 다섯 지점을 한꺼번에 조였다는 점이 이번 릴리즈의 무게중심입니다. 트랜스크립트와 샌드박스, 호스트 환경 상속, MCP stdio, Codex HTTP까지 함께 묶었으니 운영 환경에 OpenClaw를 끼워 둔 팀이라면 검토할 가치가 있습니다. 권한 모델이 평소와 다르게 보이는 부분이 있다면 이 변경이 원인일 가능성이 높습니다.

매일 쓰는 사용자라면 텔레그램·iMessage 안정화가 가장 먼저 와닿을 겁니다. 도구 호출 중간에 잘리지 않는 스트리밍, iMessage의 끈질긴 재연결, 그리고 블록 스트리밍은 체감 품질을 그대로 끌어올립니다.

자동화에 브라우저를 쓰는 분들에게는 기존 세션 CDP 지원이 결정적입니다. 매번 새 브라우저를 띄우지 않고 사용자의 로그인 상태를 그대로 활용할 수 있게 됐기 때문입니다.

마지막으로, 컨트롤 UI 시동 지연이 줄어든 만큼 자주 켜고 끄던 사용자에게 누적 효과가 큽니다. 카탈로그 대기 제거와 슬래시 커맨드 지연 로딩이 같이 작동하니 첫인상부터 다릅니다.
