## 개요

OpenClaw v2026.5.28이 나왔다. 이번 릴리즈는 에이전트·Codex 런타임의 내구성을 높이는 데 집중한다. 서브에이전트 작업 디렉터리 분리, 훅 컨텍스트 격리, 세션 락 타임아웃 처리가 모두 손봐졌다. Claude Opus 4.8 지원 추가, 채널별 메시지 전달 정합성 개선, CLI 오류 조기 감지도 이번 릴리즈에 담겼다.

---

## 핵심 요약

- **에이전트 런타임 복구**: 서브에이전트 cwd/워크스페이스 분리 강화, 훅 컨텍스트 프롬프트 로컬화, 스테일 재시작 컨티뉴에이션 방지
- **Codex 격리**: app-server·helper 장애가 공유 런타임 상태를 무너뜨리지 않도록 분리
- **Claude Opus 4.8 지원**: Fal Krea 이미지 스키마, NVIDIA 추천 모델, MiniMax 스트리밍 음악 응답, 암호화 PDF 추출 추가
- **채널 정합성**: Matrix 룸 ID, iMessage 리액션 승인, Slack 최종 답장, Telegram 폴링, Microsoft Teams 서비스 URL 신뢰 검사 개선
- **CLI·인증 경로**: 잘못된 숫자·버전 옵션 조기 거부, 레거시 api_key 프로파일 정규화 마이그레이션
- **플러그인·Gateway 캐시**: 설치 레코드·config JSON·툴 서치 카탈로그·세션 스토어 중복 연산 제거

## 본문

### 에이전트·Codex 런타임 복구

서브에이전트가 cwd와 워크스페이스를 상위 에이전트와 독립적으로 유지한다. 이전에는 서브에이전트가 부모의 작업 디렉터리를 공유하면서 파일 충돌이 발생할 수 있었다.

훅 컨텍스트는 이제 프롬프트 로컬로 격리된다. 이전 훅이 남긴 상태가 다음 훅 실행에 영향을 주던 문제가 해결됐다.

세션 락 처리도 정리됐다. 타임아웃으로 중단된 세션의 락은 해제되지만, 실행 중인 OpenClaw 락은 정리 루틴에서 살아남는다. 스테일 재시작 컨티뉴에이션이 불필요하게 쌓이는 문제도 막았다.

Codex 장애 격리가 특히 중요하다. app-server나 helper 프로세스 장애가 공유 런타임 상태 전체를 무너뜨리던 문제가 해결됐다. Codex 한 쪽이 죽어도 나머지 세션이 계속 살아있게 된다.

### 채널 전달 정합성

이번 릴리즈에서 손본 채널이 넓다.

**Matrix**: 아웃바운드 플러그인 훅, 룸 ID 정합성 개선.

**iMessage**: 리액션 기반 승인 처리가 더 안정적으로 동작한다.

**Slack**: 최종 답장 전달 경로 정리.

**Discord**: 복구된 도구 경고 메시지 전달 개선.

**Telegram**: 폴링 안정성 향상.

**WhatsApp**: 프로파일 인증 루트 처리 개선.

**Microsoft Teams**: 서비스 URL 신뢰 검사가 더 엄격해졌다.

### 모바일·채팅 인터페이스

iOS Pro UI가 리프레시됐다. 호스트 푸시 릴레이 기본값 조정, Talk 탭 실시간 재생, Gateway 채팅 트랜스포트, 온보딩, Talk 권한, WebChat 재연결 전달, 세션 피커 동작이 리커넥트와 빈 검색 상황에서 상태를 더 잘 보존한다.

### 프로바이더·미디어 확장

**Claude Opus 4.8** 지원이 추가됐다. Fal Krea 이미지 스키마, NVIDIA 추천 모델, MiniMax 스트리밍 음악 응답, 암호화 PDF 텍스트 추출, 음성 모델 카탈로그도 이번에 추가됐다.

**GitHub Copilot 에이전트 런타임** 지원과 **Codex Supervisor 플러그인 경로**도 포함됐다. Codex 워크플로를 위임 방식으로 구성할 수 있게 된다.

### 브라우저·자동화 입력 검증 강화

Browser 도구 타임아웃, 뷰포트/탭 인덱스, Gateway 포트, 크론 재시도, Discord 컴포넌트 ID, 스키마 배열 레퍼런스, Telegram 콜백 페이지, 채널 진행 콜백이 잘못된 값을 더 이른 시점에 거부한다. 의도한 전달 컨텍스트가 중간에 깨지는 경우가 줄어든다.

### CLI·인증·doctor 경로

잘못된 숫자·버전 옵션을 입력하면 이제 즉시 거부한다. 워크스페이스 dotenv 프로바이더 크리덴셜은 무시된다. 하트비트 기본값, OAuth·토큰 만료, 로컬 서비스 시작 요청에 경계값이 생겼다. 에이전트 인증 상태 레이블이 더 명확해졌고, 레거시 api_key 인증 프로파일이 표준 형식으로 마이그레이션된다.

### 플러그인·Gateway 캐시 최적화

설치 레코드, config JSON 파싱, 툴 서치 카탈로그, 세션 스토어, 매니페스트 모델 행, 자동 활성화 플러그인 config, 브라우저 토큰, 뷰어 에셋, 릴리즈 분할 외부 플러그인 패키지에서 중복 연산이 제거됐다. 캐시 정합성은 유지하면서 핫 패스 부하가 줄었다.

## 실무자가 볼 핵심 포인트

Codex 장애 격리와 서브에이전트 워크스페이스 분리는 멀티에이전트 파이프라인을 프로덕션에서 운용하는 팀에게 즉각적인 이점이다. 한 에이전트의 실패가 전체 세션을 무너뜨리던 상황이 해결됐다.

Claude Opus 4.8 지원은 최신 모델을 바로 연결할 수 있다는 뜻이고, Codex Supervisor 플러그인 경로는 Codex 위임 워크플로를 구성하는 새로운 방법을 열어준다.

채널 정합성 개선은 Telegram·Teams·Slack을 비즈니스 워크플로에 연결한 팀에게 체감 안정성을 높인다. 특히 Teams 서비스 URL 신뢰 검사 강화는 엔터프라이즈 환경에서 중요하다.
