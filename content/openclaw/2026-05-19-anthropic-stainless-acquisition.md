- 앞으로 hosted Stainless 제품과 SDK generator는 Anthropic 중심으로 재편된다.

---

## 기: Anthropic이 산 것은 단순한 개발 도구가 아니다

Anthropic이 dev tools 스타트업 **Stainless**를 인수했다. 표면적으로는 SDK 생성 도구 인수처럼 보이지만, 핵심은 더 크다. AI 에이전트가 외부 소프트웨어와 연결되는 시대에는 **API를 얼마나 안정적으로 다룰 수 있는가**가 곧 플랫폼 경쟁력이 된다.

## 승: Stainless는 왜 중요했나

TechCrunch에 따르면 Stainless는 전 Stripe 엔지니어 Alex Rattray가 2022년에 만든 스타트업이다. 이 회사의 도구는 API specification을 바탕으로 Python, TypeScript, Kotlin, Go, Java 등 여러 언어의 production-ready SDK를 자동 생성하고 유지한다.

OpenAI, Google, Replicate, Runway, Cloudflare 같은 회사들이 Stainless를 사용한 이유도 여기에 있다. API가 바뀔 때마다 SDK를 수동으로 고치는 것은 느리고 비용이 크다. Stainless는 이 과정을 자동화해 개발자 경험을 안정적으로 유지해왔다.

## 전: 경쟁사의 인프라가 Anthropic 안으로 들어갔다

이번 인수의 의미는 분명하다. Anthropic은 경쟁 AI 기업들도 사용하던 핵심 인프라 공급자를 자기 생태계 안으로 끌어들였다. TechCrunch는 Anthropic이 hosted Stainless 제품, including SDK generator를 단계적으로 종료할 것이라고 전했다.

다만 기존 고객이 이미 생성한 SDK는 계속 소유하고 수정·확장할 권리를 가진다. 그래도 앞으로 Stainless의 핵심 역량은 Anthropic의 Claude 플랫폼에 집중될 가능성이 높다.

## 결: AI 에이전트 경쟁은 ‘모델’ 밖에서 갈린다

이번 인수는 AI 경쟁이 모델 성능만으로 끝나지 않는다는 신호다. 에이전트가 실제 업무를 처리하려면 수많은 API와 안정적으로 연결되어야 한다. 그 연결을 만드는 SDK, 문서, developer experience가 곧 제품의 힘이 된다.

Anthropic의 Stainless 인수는 **AI 에이전트 시대의 인프라 전쟁**이 시작됐다는 의미로 봐야 한다.
